# cats-cross-breeds-gen-ai
Generative AI project that's based on a cat breeds Kaggle dataset. Generates cross breeds of 59 different cat breeds. 

## Note
The original Google Colab project includes multiple cells with generated images of different breeds/cross-breeds, including a cell with generated images for every single breed. Since the file is too large for GitHub, the full project can be viewed here: [https://colab.research.google.com/drive/1SWtNlJWXeB8Hkvfb8DpKPf5MeAwmkfYf?usp=sharing ](https://colab.research.google.com/drive/1SWtNlJWXeB8Hkvfb8DpKPf5MeAwmkfYf?usp=sharing)
